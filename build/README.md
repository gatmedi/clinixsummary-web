# Build-time prerender (SSG)

This site is a vanilla-JS SPA, but **crawlers get real server-rendered HTML**: every
route × locale is prerendered into a physical `<locale?>/<slug>/index.html` at the
repo root, generated by the site's own runtime (pages + i18n + SEO module) in
headless Chromium. The SPA hydrates on top and behaves exactly as before.

## Files

| File | Purpose |
|---|---|
| `build/config.json` | Single source of truth: origin, locales, routes, aliases, EN-only routes. **Add new routes here AND in `js/app.js`.** |
| `build/prerender.mjs` | The generator (`npm run prerender`). Local static server + Playwright snapshot + head/link post-processing. |
| `build/verify.mjs` | The gate (`npm run prerender:check`): canonical, unique titles, hreflang reciprocity, lang/dir, content, host-leak, link-form checks for every page. |
| `shell.html` | The **pristine SPA shell** (bootstrapped from the original `index.html`). Root `index.html` is OVERWRITTEN by the generated EN homepage — edit the shell, not the generated file. |

## Workflow

```
npm install                 # once
npm run prerender           # regenerate all pages (~280 files)
npm run prerender:check     # verify — must pass before committing
```

Commit the regenerated pages together with the source change that caused them.

## How it works (per page)

`window.BASEPATH` (the existing GitHub-Pages subpath mechanism) doubles as the
locale prefix: `/fr/...` pages bake `BASEPATH="/fr"`, so the router, link
interceptor and nav highlighting all work unchanged. `i18n.js` resolves the
locale **URL-prefix-first**; the language switcher navigates between locale URLs
on prerendered pages. The runtime `SEO` module sets the localized title/meta —
the prerenderer captures that and adds: correct-origin canonical (aliases →
target), the 6-locale hreflang cluster + x-default, `og:url`/`og:locale`,
absolutized asset refs, locale-prefixed + trailing-slash internal links.

English-only routes (`nonTranslatedRoutes`) are built once, with no hreflang.

## Serving model (production)

`php artisan website:sync` copies the repo into the platform's `public/`; nginx
(`try_files $uri $uri/ /index.php`) serves the generated files **statically,
before Laravel** — the Laravel catch-all remains the fallback for anything
unbuilt. Rollback = revert the commit and re-sync.
